# İkiyön Tech — Next.js

## Kurulum
npm install

## Geliştirme
npm run dev   -> http://localhost:3000

## Build
npm run build && npm start

- src/app/api/contact  iletişim formu API route'u (şimdilik console.log, ileride DB/backend'e bağlanır)
- src/components/* Nav, Rail, PageTransition, HeroCanvas, AboutDiagram, ServiceCard, ContactForm, Reveal
- src/app/globals.css  tüm tasarım/animasyonlar
